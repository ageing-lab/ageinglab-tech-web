Trabajamos junto a GMV en un proyecto de integración de sistemas de salud.

El encargo era desarrollar un sistema basado en el estándar FHIR para que el historial clínico se comunique entre sistemas de salud de forma estándar.

Problema

El historial clínico es información que comparten distintos sistemas de salud: plataformas hospitalarias, sistemas de atención primaria y herramientas propias de cada organización.

Sin un estándar común, cada integración requiere un canal específico para cada par de sistemas, y la información clínica queda fragmentada o difícil de mantener.

Solución

Desarrollamos un sistema de comunicación con el historial clínico basado en el estándar FHIR, el estándar de intercambio de datos de salud. El sistema permite que los distintos sistemas de salud expongan y consuman información clínica siguiendo las mismas reglas, sin acoplarse a una sola plataforma.

  • Sistema de FHIR: recursos y servicios definidos por el estándar de intercambio de datos de salud.
  • Comunicación con el historial clínico de forma estándar entre sistemas de salud.
  • Interoperabilidad: cualquier sistema que hable FHIR puede conectarse al mismo mecanismo.

Es el tipo de trabajo que hacemos en software a medida.

Y para ver cómo se integra un sistema con FHIR paso a paso, hay una guía: Cómo integrar tu sistema de salud con FHIR

Resultados

GMV cuenta con un sistema de FHIR que comunica el historial clínico de forma estándar.

La información clínica se intercambia entre sistemas siguiendo el estándar, lo que facilita la interoperabilidad y evita desarrollos a medida en cada integración.
